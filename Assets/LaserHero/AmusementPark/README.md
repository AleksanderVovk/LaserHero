# Парк аттракционов

`Assets/Scenes/Lobby.unity` → `LaserHeroWorld/Amusement Park Arena`.

408 отдельных разрушаемых объектов, карта 128×128 м, грунт глубиной 16 м. Предыдущие арены сохранены выключенными. Геометрия разных объектов не объединена.

Группы: грунт и дорожки; американские горки (шесть отдельных секций), вагончики и качающийся пиратский корабль; колесо обозрения с 12 кабинами и башня падения; две карусели и двое двойных качелей; павильон с машинками; входная арка и билетные кассы; киоски и воздушные шары; фонтан, скамейки, ограждения, фонари и деревья.

Это разрушаемые декорации арены. Автоматическое движение аттракционов и посадка игрока на аттракционы не добавлялись.

Палитра яркая и контрастная, с умеренно сниженной насыщенностью кислотных оттенков. Пастельный вариант заменён по просьбе пользователя.

Генератор — `Assets/LaserHero/Editor/LaserParkSetup.cs`. Формы — `Assets/LaserHero/Runtime/LaserParkShapes.cs`, стили 70–89. Цвета отдельных объектов — `LaserVoxelBody.surfaceColors`.

Спицы колеса исправлены: диагональные лучи связаны с центральной втулкой и ободом. Проверка связности всех объектов парка: 0 несвязанных с основанием компонентов. Меши и коллайдеры присутствуют, компиляция без ошибок.
