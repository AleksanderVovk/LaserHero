## Настройка компонента Laser Training Target

- Tier: постоянный уникальный ID дорожки (0–31). Покупки сохраняются по нему, поэтому после публикации не меняй ID существующих дорожек.
- Training Multiplier: множитель получаемого опыта при тренировке. 0 сохраняет старое значение по Tier; в готовом ряду значения выставлены явно.
- Access: Free, Rebirths или IAP.
- Required Rebirths: требуемое общее число перерождений. Это условие доступа, перерождения НЕ тратятся. Дорожка автоматически становится доступной при достижении порога.
- Iap Product Id: ID отдельного постоянного товара Google Play.
- Iap Price: числовая цена предпросмотра, например 5.99. В Android цена берётся из магазина после загрузки данных товара.
- Radius: радиус начала тренировки.

Над мишенью — округлая чёрная плашка и оранжевая надпись множителя. У Free и Rebirths показана иконка перерождения, у IAP только числовая цена. Изменения настроек видны в редакторе.

На платную плашку можно нажать для покупки; рядом с мишенью также работает E. После открытия IAP-дорожка сохраняется и восстанавливается через общий Unity IAP. Дорожки с порогом перерождений открываются автоматически. Начало тренировки — при приближении к доступной мишени. Уход с дорожки прекращает тренировку.

## IAP

Четыре товара дорожек добавлены в GooglePlayCatalog.asset. Всего теперь 17 товаров. При запуске компонент LaserIAPStore собирает актуальные IAP-дорожки сцены в копию каталога, поэтому изменение ID/цены на дорожке подхватывается при следующем Play Mode без ручного дублирования настроек в каталоге. Только дорожки Access=IAP становятся товарами магазина.

Google Play Console пока требует создания приложения и товаров. Все четыре ID нужно создать как NonConsumable с соответствующими ценами. В редакторе работает Unity Fake Store, без списания денег.
