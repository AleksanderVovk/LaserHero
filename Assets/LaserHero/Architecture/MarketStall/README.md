# LEGO Market Stall

Префаб: Assets/LaserHero/Architecture/MarketStall/LEGOMarketStall.prefab.

Декоративная торговая лавка без продавца, по четырём референсам: голубой полосатый навес, четыре стойки, прилавок, ящик с X-раскосами, бочка и голубой фонарь, три лотка, подвесные светильники, маленькие красные и синие LEGO-грибы.

Перетащи префаб в сцену и расположи его. Внутри 9 подписанных групп. Для изменения цвета в режиме редактирования выбери деталь и измени Block Color у компонента Laser Arch Block. Для изменения яркости товаров открой Amber Magic, Lime Magic или Cyan Magic материалы. Все обычные детали используют существующую LEGO-текстуру и нормали проекта.

В Play Mode LaserStallRenderBatch объединяет 115 обычных деталей в один меш с 8 цветами вершин (1720 треугольников). Светящиеся детали остаются отдельными (12 Renderer). Исходные геометрические объекты и коллайдеры сохранены; исходные Renderer скрываются, чтобы не дублировать картинку. Цвета объединённого меша запекаются при старте Play Mode, поэтому цветовые правки делай до запуска.

Проверено: компиляция без ошибок, вид спереди и сзади, создание runtime-меша с цветами, отсутствие дублирующих Renderer. Превью: LEGO-Market-Stall.png и LEGO-Market-Stall-Rear.png в outputs текущего чата.
