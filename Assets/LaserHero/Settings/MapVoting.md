# Ротация арен и голосование

В сцене `Lobby` выберите `LaserHeroWorld/Arena Rotation` → компонент `LaserArenaRotation`.

- `Round Interval Seconds` — длительность игрового раунда, по умолчанию 180 секунд.
- `Round Timer Text` — перетащите сюда свой TMP-текст. Формат: `Сброс карты через 3 минут 0 секунд!`. Отсчёт идёт до начала голосования; во время голосования и подготовки показывает 0 минут 0 секунд, после загрузки карты начинается заново. Ссылка по умолчанию пустая.
- `Voting Seconds` — длительность голосования, по умолчанию 10 секунд.
- `Starting Arena Id` — первая карта, по умолчанию `city`.
- `Lobby Barrier` — ссылка на объект стены. Объект включается при голосовании и подготовке карты, выключается после её готовности. Держите стену вне корней арен и объекта самой ротации. Ссылка оставлена пустой для вашей стены.
- `Maps` — список всех карт. `Enabled In Rotation` исключает карту из ротации; `Title`, `Icon`, `Root`, `Bounds` и `Entry` редактируются для каждой карты. Резервный прототип по умолчанию выключен.
- `Preparation Bodies Per Frame` и `Preparation Budget Milliseconds` — лимиты подготовки разрушаемых объектов за кадр, по умолчанию 8 объектов и 4 мс. Один неделимый объект может потребовать больше этого времени.

Каждый запуск начинается с города. В конце раунда игрок перемещается в лобби, открывается голосование, включается стена и запрещается вход/разрушение арены. Из включённых карт выбираются три разные карты, кроме текущей. Если кандидатов меньше трёх, показывается доступное количество.

Нажатие карточки записывает голос; до конца отсчёта выбор можно изменить. Кнопка X и Escape закрывают окно, сохраняя сделанный выбор. Без голоса случайно выбирается одна из предложенных карт. Закрытое окно не останавливает отсчёт. Исключение действует только для текущей карты: предыдущие карты снова могут появиться в следующем голосовании.

Старая арена выключается, обломки и огонь удаляются. Новая подготавливается несколькими порциями, восстанавливаются разрушенные клетки и частичный урон. Целые уже загруженные объекты повторно не перестраиваются. После подготовки включается только выбранная арена и убирается стена. Игрок остаётся в лобби и может снова выйти на арену. Геометрия разных объектов не объединяется.

Если включена единственная карта, она восстанавливается в конце раунда без пустого голосования. Если выключены все карты, ротация ждёт включения хотя бы одной карты, не открывая пустое окно.

Интерфейс сохранён в `LaserHeroWorld/HUD Canvas/Map Voting`. Размер регулируется параметром `Preferred Width` у компонента `LaserMapVoteUI` на `HUD Canvas`; по умолчанию 900, ширина магазинов — 780. Весь интерфейс масштабируется пропорционально и дополнительно уменьшается при нехватке места на экране.

Старый автоматический сброс `LaserArena.roundDuration` не запускается, пока работает ротация. Покупки, уровень, деньги и остальные сохранения игрока при смене карт не сбрасываются.
