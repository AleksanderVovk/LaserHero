# Иконки арен — 512×512

Все PNG имеют размер 512×512 и импортированы как Sprite (Single), без mipmaps и сжатия. Иконки отрендерены из настоящих моделей арен, без HUD и надписей.

- `Arena_City.png` — город.
- `Arena_Spaceport.png` — космодром.
- `Arena_Ocean.png` — морская арена.
- `Arena_AmusementPark.png` — парк аттракционов.
- `Arena_Prototype.png` — дополнительная иконка резервной прототипной арены.

Экспорт не меняет включённую арену и не перестраивает исходные модели. Иконки готовы для поля Sprite у UI Image; автоматическое подключение к меню выбора арен не добавлялось.

Обновление после изменения карт: `Laser Hero → Render all arena icons 512` в Edit Mode. Генератор — `Assets/LaserHero/Editor/LaserArenaIconSetup.cs`. Общий лист предпросмотра — `F:/LaserHero/LaserHeroQA/ArenaIcons-ContactSheet.png`.
